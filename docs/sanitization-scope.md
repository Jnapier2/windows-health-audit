# Sanitization scope

This public repository was derived conceptually from a private Windows operations package. The original package was **not** published or copied wholesale.

## Included

- a newly sanitized, standalone read-only health snapshot script;
- de-identified operating-system, memory, storage, network, security, update, Event Log, and reliability summaries;
- transparent review thresholds and failure-isolation patterns;
- a synthetic JSON example;
- architecture, privacy, and safety documentation; and
- PowerShell parse and forbidden-capability checks.

## Excluded

- launchers, installers, relocators, trust-setup and file-unblocking helpers;
- WinGet allowlists, update execution, update configuration drafts, and update planning tied to a private environment;
- optimization, repair, cleanup, tuning, remediation, firewall, service, registry, process-control, and network-change logic;
- assistant-specific prompt generation, external handoff bundles, transfer briefs, and internal review ledgers;
- private hardware reports, system-aware primers, machine-specific configuration, paths, and generated diagnostics;
- manifests, build/export metadata, known-good snapshots, package history, and legacy repair history;
- binaries, archives, imported reports, runtime state, and full-batch output; and
- operational source from the broader private controller.

No real report from the private environment is included. The example values and provider names are synthetic.
